# Remaining dependency findings — 2026-10-12

Fresh full audit: 48 package findings; production-only audit: 47. Before: 56. Removed package findings: lodash, nanoid, preact, protocol-buffers-schema, qs, sharp, source-map-js, ws. No uncontrolled major upgrade, production deployment or service request was used to obtain this result.

The supported isolated alias retains Nodemailer 10.0.9; Next 15.5.27, NextAuth 4.24.15 and Axios 1.20.0 remain exact. Next's image optimizer is reachable in current production (read-only JPEG probe returned 200); a controlled Sharp 0.35.5 override is covered by an actual Next optimizer test. Compatible updates patch Preact, ws, qs, protocol-buffers-schema, source-map-js and root PostCSS. Lodash 4.18.1 is a same-major override of the map SDK's exact vulnerable pin, tested for merge behavior and prototype isolation.

Next's bundled/pinned PostCSS 8.4.31 still has build-input findings. No public CSS compiler was found; the root PostCSS update does not repair this nested copy. Next itself has no direct advisory in this audit response. Keep the verified Next version and track a separately demonstrated nested update. CLI findings include the critical tar advisory; they are not reachable through application imports, but remain toolchain risk. Remaining unknown exploit prerequisites are recorded as unknown, never declared safe merely because a package is transitive.
